# Juegos, Bytes y Malas Decisiones

> *“Todo empezó con problemas estúpidos en juegos…
> y terminó en ingeniería inversa.”*

---

## ¿Qué es este repositorio?

Este repo es una colección de herramientas, scripts y experimentos creados a partir de:

* bugs molestos
* curiosidad técnica
* ganas de romper cosas (y entenderlas)
* y decisiones cuestionables dentro de videojuegos

Lo que empieza como:

> *“quiero más armas”*

termina en:

* parsers binarios
* análisis de formatos propietarios
* edición directa de memoria/archivos
* herramientas reutilizables para otros

---

## Estructura

```id="jv2k1c"
juegos/
 ├── ultrakill/
 │    └── UltraKillDecoder.py
 ├── (futuros juegos…)
```

Cada carpeta representa un juego…
y un problema que se salió de control.

---

## Filosofía del proyecto

Este repo sigue una idea muy simple:

> **No hay problema demasiado tonto si te obliga a aprender algo complejo.**

Aquí:

* errores → aprendizaje
* frustración → herramientas
* curiosidad → conocimiento reutilizable

---

## Ejemplo actual

### ULTRAKILL

Problema:

> “Quería modificar mi progreso / armas”

Resultado:

* Decoder de `.bepis`
* Editor binario interactivo
* Exportación a texto
* Análisis de serialización tipo C#

## ⚠️ DISCLAIMER GENERAL

Este repositorio existe con fines:

* educativos
* de investigación
* modding offline

No está diseñado para:

* afectar a otros jugadores
* romper sistemas en línea
* uso malicioso

---

### ⚖️ Sobre los juegos

Todos los juegos mencionados pertenecen a sus respectivos autores.

Este repositorio:

* **no está afiliado**
* **no distribuye contenido del juego**
* solo analiza formatos y comportamientos desde un punto técnico

---

## Lo importante

Este repo no trata sobre “hacer trampa”.

Trata sobre:

* entender cómo funcionan las cosas por dentro
* perderle el miedo a formatos binarios
* aprender haciendo cosas inútiles… que dejan de serlo
